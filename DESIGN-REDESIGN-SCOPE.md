# With Little — Porsche Black/Blue Redesign Scope

## Non-negotiable product boundary
This is a redesign of the existing With Little application, not a new companion app or alternate product.

Preserve:
- current routes, views, tabs, workflows, and forms
- current Supabase data model and sync behavior
- current daily planning, habits, stewardship, projects, ideas, journal, stones, mentorship, guide, profile, and authentication functionality
- current responsive behavior unless an intentional visual refinement improves it

Change:
- the visual system across the entire app
- layout polish, hierarchy, motion, spacing, typography, states, cards, navigation, controls, and data visualization
- the default cream/gold palette into a premium black, midnight, and electric-blue system

## Aesthetic direction
- Porsche-level restraint, precision, material quality, and cockpit clarity
- nearly black graphite surfaces, midnight blue depth, controlled electric-blue highlights
- glass, carbon-fiber texture cues, machined borders, subtle reflections, instrument-cluster legibility
- advanced and premium without becoming neon gamer UI
- cinematic but highly usable; no Pinterest collage treatment
- motion should feel mechanical, precise, and quiet

## Product philosophy
The app remains Christ-centered. Performance, body, career, systems, influence, money, and aspirational objects remain subordinate ends. The interface should reinforce identity, rest, faithfulness, stewardship, and service without turning the app into a separate branded philosophy product.

## Phase 1
1. Replace global design tokens and typography.
2. Redesign the existing sidebar, top bar, page shell, cards, inputs, buttons, tabs, modals, empty states, and feedback states.
3. Preserve every existing selector and JavaScript hook unless a tested refactor is required.
4. Validate all major current views on desktop and mobile.
5. Ship as a preview PR before production merge.
